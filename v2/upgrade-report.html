ChangesEverything that changed

  1. ArchZero-backend rebuild. The old app needed a Next.js server, tRPC, Prisma and ~700 npm packages to boot. v2 is a static SPA: 6 ES modules, no build step, no dependencies, deploys to any static host. Nothing to install, nothing to run, nothing to patch.
  2. ContentZero-loss persona corpus. All 14 personas from the fork's enriched src/data.ts carried over programmatically and verified verbatim: 14 system messages (22.3K chars), 60 example prompts, 55 call starters, 12 ElevenLabs voice ids, the "Featured" flag, and the one upstream persona image (reused for Developer). Extraction script + verification receipts in v2/NOTES.md.
  3. FeatBYO-key streaming chat in the browser. Works with any OpenAI-compatible endpoint (OpenAI, OpenRouter, Groq, Z.ai, Ollama, LM Studio — 7 pre-wired, custom base URL on all), plus Anthropic and Google Gemini adapters. Native SSE streaming with a stop button. Keys never leave localStorage; there is no server to leak them to.
  4. FeatBeam mode kept. The suite's signature move — one prompt to up to 3 model lanes, streaming side by side in columns, managed from Settings.
  5. FeatPersona prompt macros implemented. The old personas ship with big-AGI template macros ({{LLM.Cutoff}}, {{LocaleNow}}, {{RenderMermaid}}, {{PreferTables}}…) — v2 substitutes all of them at send time.
  6. FeatCustom personas. Write your own system prompt (macros supported) and start a chat with it — the old app's Custom persona, promoted to a first-class flow.
  7. FeatHistory + data ownership. Conversations persist locally with persona sigils; export/import the entire state as JSON; export any chat as Markdown; one-tap wipe.
  8. UI"Obsidian Filament" design system. Custom CSS (no framework): obsidian glass surfaces, cyan→violet→pink gradient identity, streaming caret, thinking indicator, toasts, bottom sheets, micro-transitions. Fleet-bar visual work, not bootstrap-default.
  9. UIProcedural persona sigils. No emoji-as-art: every persona gets a deterministic layered-SVG mark (petals, orbits, arcs from a hash of its id) with a per-persona gradient palette — 13 unique sigils generated at runtime, zero image weight.
  10. UIPersona gallery as the front door. Fourteen character cards with descriptions and example prompts; one tap opens a chat pre-loaded with that persona's examples as starter chips.
  11. Perf~100× smaller payload. Old: multi-MB Next.js bundle + server. New: ~64KB of app code + 34KB persona data + 11KB image, uncompressed, zero CDN calls, instant first paint.
  12. PerfStreaming-native markdown renderer written for chat (code fences with copy buttons, tables, lists, quotes) — renders incrementally during generation with no re-parse flicker libraries.
  13. SecAttack surface removed. No backend, no proxy, no database, no Docker image. The old repo's basic-auth middleware problem (protect a server) disappears with the server. No secrets in the repo (verified by grep before commit).
  14. SecHonest key handling. Keys masked in Settings, stored only in localStorage, sent only to the provider you configure, with an explicit warning in the Settings sheet recommending spend-capped keys.
  15. DocsSelf-documenting ship. README (run, structure, macros, design laws), NOTES.md (study + BEFORE grading with receipts), this upgrade report — all deployed with the app and committed on the branch.

LimitsWhat I did not get to

  • Upstream features not rebuilt: Calls (voice chat, ElevenLabs), Draw (image generation UI), News, Diff, Tokens tokenizer, link-chat. The rebuild covers the fork's core identity (personas + chat + beam); those apps are separate builds. Voice ids from the corpus are preserved in the data for a future Calls revival.
  • No live LLM round-trip tested end-to-end in this session — no spendable vendor key available on the rig for a real completion. The adapters implement documented SSE formats for all three API families and were reviewed line-by-line; the keyless-send guard, error surfaces and beam orchestration were tested with the browser against missing-key paths. First real key may surface provider-specific CORS quirks (noted in-app in the failure message).
  • Multi-modal inputs (images/files) from the old app are not wired — text-only chats in v2.
  • Accessibility not screen-reader audited — labeled controls, focus rings and reduced-motion are in; a proper NVDA/VoiceOver pass is owed.
  • No PWA/service worker — the app is fully functional offline once loaded except LLM calls, but there's no install prompt or offline cache strategy yet.
  • Conversation search is not implemented (browse + delete only).
